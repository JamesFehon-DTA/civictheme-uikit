# Promo

Highlights a single featured item with an image and call to action.

<Canvas of={Stories.Promo} />

<Controls of={Stories.Promo} />

Use a promo to draw attention to a single item (a publication, event, program, or page) with a visual and a short call to action. The component pairs an image with a heading, brief description, and link.

## When to use

- you want to draw attention to one specific item within a page or sidebar
- the item has an image that adds context and visual interest
- a single clear call to action follows from the featured content

## When not to use

- to feature more than one item – use a card grid or **Feature link list** for multiple items
- when no suitable image is available – a promo without an image loses its visual purpose
- as the page header – use **Banner** instead
- for process content – use **Timeline** for ordered steps

## Related components

- **Campaign** – use for a major editorial feature rather than a single highlighted item.
- **Feature link list** – use to present a group of related navigational links.
- **Banner** – use as the page-level header rather than an in-page feature.
